## Dependencies

- [tree-sitter-cli](https://tree-sitter.github.io/tree-sitter/)

- [nodejs](https://nodejs.org/)

- nvim (duh)

### Arch Installation

```bash
sudo pacman -S nodejs treesitter-cli
```

### Windows Installation

```bash
npm install -g tree-sitter-cli
```

### Ubuntu Installation

```bash
sudo apt install nodejs npm
npm install -g tree-sitter-cli
```

## installation

after installing all the dependencies you can procede to the installation

1. go to your config file in linux and mac it is in ~/.config and in windows it is in C:\Users\<your-username>\AppData\Local

2. move your old config somewhere else

3. clone the repo using the command ;

```bash
git clone https://github.com/hakabol/nvim.nvim nvim
```

4. now you are done and can enjoy nvim
